# [QA] 제휴 연동 상품, 제휴상품번호 & 배송주체 통합 대시보드

테스트(QA) 환경에서 100일 이내 재고 있는 상태로 연동된 상품을 채널별/제휴사별로 실시간 조회하고, 상품번호, 제휴상품번호, 배송주체(shppMainCd), 영업점/사이트번호를 자동 조회 및 추출하는 웹 대시보드 및 자동화 도구입니다.

- **GitHub Pages 웹 대시보드**: https://loren-kim.github.io/bo-alln-project-03/
- **로컬 대시보드**: `index.html` (또는 `qa_item_finder.html`)

---

## 🌟 주요 기능 및 특징

### 1. 웹 브라우저 실시간 선연동 CSV 업로더 (드래그 앤 드롭 지원)
- **간편한 드롭 반영**: BO에서 내려받은 `선연동_*.csv` 파일을 웹 브라우저 화면 아무 곳에나 마우스로 끌어다 놓기만(Drag & Drop) 하면 끝납니다.
- **로컬 스토리지 보존**: 브라우저 `localStorage`에 자동 저장되므로 페이지를 새로고침해도 영구 유지됩니다.
- **헤더 파일 선택 지원**: 상단 `[📂 선연동 CSV 불러오기]` 버튼을 통해 복수 CSV 파일 일괄 선택도 가능합니다.

### 2. 업무시간 자동 동기화 & 다운로드 감시 데몬 (`auto_sync_daemon.py`)
- **평일 업무시간(09:00~19:00) 1시간 정기 배치**: 별도 작업 없이 1시간마다 최신 현황을 자동 조회하여 대시보드와 엑셀을 갱신합니다.
- **다운로드 감시(File Watcher)**: `~/Downloads` 폴더에 `선연동_*.csv` 파일이 새로 다운로드되면 3초 후 즉시 감지하여 자동 동기화 및 깃허브 푸시를 실행합니다.
- **명령어**:
  - 데몬 시작: `python3 auto_sync_daemon.py &`
  - 상태 확인: `python3 auto_sync_daemon.py --status`
  - 데몬 종료: `python3 auto_sync_daemon.py --stop`

### 3. 원클릭 통합 동기화 (`sync_all.py`)
- 수동 실행 시: `python3 sync_all.py`
- Downloads 폴더 내 선연동 CSV 전체 스캔 ➜ 내장 캐시 갱신 ➜ QA BO 27개 채널 크롤링 ➜ 엑셀/CSV 생성 ➜ Git 커밋 & 푸시 일괄 처리

### 4. 배송주체 컬러셋 & 빠른 원클릭 필터
- 배송주체별 시각적 컬러셋 적용:
  - `매장집하(11)`: 주황/Amber
  - `PP입고(12)`: 보라/Purple
  - `센터입고(13)`: 파랑/Blue
  - `점포PP(21)`: 에메랄드/Emerald
  - `협력업체(41)`: 회색/Slate
  - `직배(42)`: 로즈/Rose
- 상단 배송주체 범례 버튼을 클릭하여 원하는 배송주체만 1초 만에 즉시 필터링
- 엑셀 파일(`recent_all_items.xlsx`)에도 동일한 컬러셋 서식 자동 적용

### 5. 테이블 컬럼 정렬 (오름차순 / 내림차순)
- 채널명, 서비스명, SSG상품번호, 제휴상품번호, 배송주체, 영업점, 마지막연동일자 헤더 클릭 시 즉시 정렬

### 6. 번호 앞자리 '0' 완벽 보존
- 앞자리 0(예: `0000000035993`)이 엑셀에서 잘리지 않도록 텍스트 포맷(`="00..."`)으로 철저히 보존
