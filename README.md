# [QA] 제휴 연동 상품, 제휴상품번호 & 배송주체 조회

테스트(QA) 환경에서 100일 이내 재고 있는 상태로 연동된 상품을 채널별/제휴사별로 실시간 조회하고, 상품번호, 제휴상품번호, 배송주체(shppMainCd), 영업점/사이트번호를 자동 조회 및 추출하는 웹 대시보드 및 CLI 도구입니다.

## 기능 안내
- **전체 채널 일괄 조회**: 33개 제휴 연동 채널의 상품번호 일괄 스캔
- **제휴상품번호 & 배송주체(shppMainCd) 자동 연동**: 백오피스(BO) API를 통한 실시간 매핑
- **제휴사별 / 서비스별 포커스 조회**: 원하는 제휴사(G마켓, 옥션, 11번가 등) 또는 단일 하위 채널만 독립 조회
- **텍스트 포맷 보존**: 앞자리 0이 있는 상품번호(예: `0000000035993`)가 엑셀에서 잘리지 않도록 안전 처리
- **원클릭 복사 & CSV/Excel 내보내기**: 개행/콤마 단위 복사 및 지정 양식 CSV/Excel 다운로드

## 주요 파일
- `index.html`: 웹 대시보드 (GitHub Pages 배포 진입점)
- `fetch_recent_items.py`: 터미널 CLI 도구 (Python 3 표준 라이브러리 기반)
